# OMSR

This repository contains the code to reproduce the applications and simulation 
study in the paper Operator-Matched Spatial Regression. 

The folder Application1 contains the temperature application, the folder Application2
contains the NO2 application, and simulation contains the simulation study. 

The code requires the `rSPDE` package, version greater than 2.5.2. The current 
development version can be installed from R by running 
```r
remotes::install_github("davidbolin/rspde", ref = "devel")
```
